
## Дополнительные функции для задания 2.4

В графическом приложении добавлены кнопки:

- `Все диски` — запускает сканирование всех несъёмных дисков через Windows-службу.
- `Расписание` — включает периодическое сканирование всех несъёмных дисков с интервалом 60 секунд.
- `Мониторинг` — выбирает директорию для мониторинга и периодического сканирования новых/изменённых файлов.
- `Стоп монитор` — отключает мониторинг выбранной директории.

Все операции выполняются через Windows RPC. Антивирусная функциональность остаётся доступной только при активной лицензии.


## Задание 2.5 — хранение и обновление баз

Антивирусные базы поставляются вместе с продуктом в каталоге `avdb` в бинарном файле `sakura_default.savdb`.

При запуске службы файл базы копируется в `C:\ProgramData\SakuraShield\avdb\sakura_current.savdb` и загружается с диска. Формат базы компактный бинарный:

- magic `SSAVDB25`;
- версия формата;
- дата выпуска базы;
- количество записей;
- подпись манифеста;
- массив записей базы.

При загрузке служба проверяет подпись манифеста. Если проверка не проходит, выполняется восстановление из `sakura_backup.savdb`; если резервной копии нет или она тоже повреждена, загружается база по умолчанию из поставки продукта.

Каждая запись содержит prefix, длину сигнатуры, хэш сигнатуры, диапазон offset, тип объекта, имя угрозы и подпись записи. Записи с некорректной подписью пропускаются, остальные продолжают загружаться.

Также реализовано периодическое обновление базы: перед обновлением создаётся резервная копия, затем база обновляется из default package, загружается в память, а при ошибке выполняется откат на резервную копию.
